How to review

Open the source link and check the claim against that page only.

  • Correct: the page supports the claim as written (value, date, company).
  • Wrong: the page says something else, or doesn't contain the quote. A true claim with a source that doesn't back it is still Wrong.
  • Can't verify: the page doesn't load, is paywalled, or you can't decide. These count against accuracy in the strict metric, so add a short note.

Answers are kept in this browser. When done, press Export CSV and save the file as eval/labels.csv. Pack fcf0cb3122, 60 claims, seed 7.

This browser blocks local storage: answers will be lost on reload. Export before closing the page.
